## 1. 最重要的發現：18節 全部是「V4 世代」core，是 25節 KV 的前身

去空白 diff 行數（越小越近）：

```
25節 11 工具＝V5.0.0（以 V4.25.0 為底）
   ↑
25節 KV V0.2（25節 裡最舊的一份）
   ↑ 485～1439 行
18節 V4.20.3 世代 ─┬─ OM_w1 ＝ OM_w2（差 33 行）
                   ├─ network（介於 OM 與 25KV 之間，已有 KV 文字引擎）
                   ├─ 鏡面 ＝ 跨夜（差 4 行；KV 直系，不是 25節 鏡面／跨夜 的親戚）
                   ├─ AMS ≈ ENG（差 384 行）≈ KV/KOL代播圖
                   └─ A 系：暖正MS／暖身BN／正式BN（KV 前身：Price*、Geometry、切換式預覽／匯出與 KV 逐字或近乎相同；
                            25節 KV 註解「V1.0 開源版已移除」的頭巾／HBN／MALL SKBN／DEFAULT_TEMPLATE 就是 18節 還在用的東西）
例外：18節 LineOA V0.4 ＝ 25節 LineOA V0.5 ＋ 120 行純加法（唯一的 V5 世代）
```

結論：
- **不需要第三套 lineage（`_C`）**。整合版 core 以 25節 的 `_B`（ancestor／KV 旗標組）為底，18節 差異用「新旗標值＋函式級分支（`*Legacy18`）」加法併入。
- 12 個工具共用一個新 family **`v4`**（`_defaults.js` 的 `families.v4`），放 V4→V5 之間所有工具共同的行為值；LineOA 沿用 25節 `family: b`。
- 原本以為的「18節 A 系 vs 25節 A 系」比對不成立：18節 A 系不該用 `family: a`（正式BN／暖身BN／MS 的 25節 A 路徑），而是 `ancestor`＋`v4`。
